# ♟️ Web Chess Engine

Przeglądarkowa implementacja gry w szachy z interfejsem użytkownika i systemem lokalnego rankingu. Projekt demonstruje umiejętność zarządzania stanem aplikacji, manipulacji modelem DOM oraz tworzenia responsywnych interfejsów w czystym JavaScript.

## 🚀 Główne funkcjonalności
* **Zarządzanie stanem gry:** Walidacja wyboru figur i generowanie planszy.
* **Lokalna Baza Danych:** Wykorzystanie `Local Storage` do zapisywania nicków graczy i rankingu zwycięstw.
* **Nowoczesny interfejs:** Ciemny motyw (Dark Mode) z czytelnym podświetlaniem dostępnych ruchów.
* **Modularność:** Struktura kodu przygotowana pod wdrożenie pełnego algorytmu Minimax (zaimplementowany wstępny fallback AI).

## 🛠️ Wykorzystane technologie
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
* **Design:** Custom UI/UX, CSS Grid

## 💻 Jak uruchomić projekt?

Projekt nie wymaga instalacji żadnych zewnętrznych bibliotek.
1. Sklonuj repozytorium na swój komputer:
`git clone https://github.com/patrykdobrakowski/js-chess-engine.git`
2. Otwórz plik `index.html` w dowolnej nowoczesnej przeglądarce internetowej.
